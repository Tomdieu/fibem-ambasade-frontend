# Project: FIBEM-AMBASSADE-GINEA-BISSAU
This project is a frontend application built with Next.js, designed to provide an interactive user interface for the FIBEM Ambassade Guinea-Bissau initiative. The application focuses on delivering a seamless user experience while adhering to modern web development standards.

## Tech Stack
* Next.js 16 (App Router)
* React 19.2
* TypeScript
* Tailwind CSS

## Project Structure
* `/app`: App Router components and routes
* `/lib`: Utility functions and API logic
* `/components`: Reusable UI components

## Quality Gates
* `pnpm lint`
* `pnpm type-check`
* `pnpm test`
